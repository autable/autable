# 签名

用私钥给一段字符串签名，返回签名。私钥放在节点密钥里，脚本碰不到：脚本把
文本递进来，节点把签名递回去。凡是要签发一个东西、让客户端用内嵌公钥离线
校验的场景都可以用——许可证、激活码、签过名的令牌。

## 密钥

- `private_key`——PKCS#8 私钥，单行 base64 DER 或 PEM 都行。只接受 ECDSA 密钥，
  曲线从密钥本身读。

## 输入

- `data`——要签的文本。签的是它的 UTF-8 字节，原样不动：要去空白、要规整，
  在脚本里调用前做好。
- `algorithm`、`hash`、`format`、`encoding`——可选。每个只支持一个值，也就是
  默认值：`ecdsa`、`sha256`、`p1363`、`base64`。传别的直接报错，不会退回默认，
  这样按还没实现的变体写的脚本在调用处就失败。

`p1363` 是裸 `r||s` 布局，每一半按曲线长度补零（P-256 上是 64 字节）。.NET 的
`ECDsa.VerifyData` 和 Windows CNG 原生就认这个；除非校验方明确要 DER，否则用它。

## 输出

- `signature`——编码后的签名。
- `public_key`——对应的公钥，base64 SPKI。和客户端里内嵌的那把比一下，确认
  配的是同一对。
- `algorithm`、`hash`、`format`、`encoding`——实际用的参数。

节点返回前会用推出来的公钥把签名验一遍，拿到的签名一定是对应校验方会接受的。
