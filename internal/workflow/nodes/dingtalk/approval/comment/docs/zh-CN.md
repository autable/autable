# 钉钉审批评论

往审批实例下面发一条文字评论，走 `POST /v1.0/workflow/processInstances/comments`。
钉钉没有"应用发评论"的概念，每条评论都是以某个人的身份发出的，所以节点需要
一个 userId 来代言。这个人得能看到这张审批单。

## 输入

- `instance_id`——审批实例 id。
- `text`——评论内容。
- `comment_user_id`——覆盖 `comment_user_id` 变量。

## 输出

- `instance_id` 和 `comment_user_id`——钉钉接受评论后原样返回。钉钉不接受时
  直接报错，不会返回 false。

## 典型用法

工作流处理完一张审批后把结果写回审批单——生成的编码、单号、链接——发起人
和审批人在他们本来就看的地方就能看到，不用另发通知。发完在行上记一下，
重跑时就不会再发一遍。
